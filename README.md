# 植物魔法 Botania · RimWorld 1.7 移植

[![release](https://img.shields.io/github/v/release/moxuanag/Rimworld-Botania?label=release)](https://github.com/moxuanag/Rimworld-Botania/releases)
[![license](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

把《我的世界》的 **Botania（植物魔法）** 移植到环世界 1.7 的非官方模组。

魔力是一套**独立的能量体系**：不从电力网取电，也不能直接当成电池；它由花生产、由魔力池储存、
由中继塔搬运，最后可以经**魔力通量场**换回普通电力。整套玩法是「种花 → 磨粉 → 造材料 → 建池 → 铺网 → 用法杖」。

> 本仓库只存放**模组源文件**。成品由 GitHub Actions 在打 tag 时自动打包，
> 到 [Releases](https://github.com/moxuanag/Rimworld-Botania/releases) 下载 `Rimworld-Botania-x.y.z.zip` 即可。

## 零、总览

这一节把「有什么、怎么解锁、靠什么运转」集中在一处；后面各章是细节。

### 1. 数据流

```
        ┌─ 8 色花瓣 ──研磨(1200 工作)──> 魔力尘 ──+ 2 钢铁──> 魔力钢锭
        │
神秘花 ─┤
        │
        └─ 采花后留根，过一阵重新长

原木 ──白雏菊(20 魔力)──> 活木 ──┬──> 建材 / 森林法杖
石砖 ──白雏菊(20 魔力)──> 活石 ──┘

火红莲(烧燃料，30 魔力/秒) ─┐
太阳花(白天 8/秒，15 天枯)  ─┼──> 魔力池 ──> 分流到下面五个去处
夜颠茄(夜晚 4/秒，15 天枯)  ─┘

魔力池 ──┬──> 中继塔（半径 8 接力，每跳 -10%）──> 魔力通量场 ──> 1000 W 电力
         ├──> 荆棘花（半径 10 范围防御）
         ├──> 白雏菊（有池子才全速转化：5 秒/个，否则 25 秒/个）
         ├──> 建筑恢复器 / 装备修复器（按耐久扣魔力）
         └──> 森林法杖（杖内 500 储能，每发 100）
                  └─ 研究「法杖改型」后：狙击型（800 / 每发 60）、爆破型（700 / 每发 60）
```

闭环一句话：**种花得花瓣 → 磨成魔力尘 → 造白雏菊把原木石砖变成活木活石 → 建池子接住花产的魔力 → 用魔力养防御、维护和法杖，多余的电送进电网。**

### 简易魔力池 / 魔力池

| | 简易魔力池 | 魔力池 |
|---|---|---|
| 尺寸 | 1×1 | 3×3 |
| 造价 | 15 活石 + 15 活木 | 25 魔力钢 + 20 活木 |
| 容量 | **2 000** | **100 000** |
| 研究 | **魔力** | **魔力存储** |

- **均摊**：每 **250 tick（≈4.2 秒）** 与自己**紧贴**（含斜角）的池子把差值对半分，
  所以一排放几个池子会自动拉平水位，不用手动灌；
- 只做储能，不自带发电。

> 简易池是**开局那一档**：活石活木自己就能造，2000 容量够喂一两座白雏菊。
> 等研出**魔力存储**，再换成大池子把整座基地的储备收进一处。
> 两种池子可以混着放，均摊逻辑一视同仁。

### 火红莲（产魔）

| 项 | 值 |
|---|---|
| 燃料 | 原木 / 活木 / 化合燃料（可自动补充、可弹出） |
| 燃料仓 | 50 单位 |
| 单产 | **1 单位燃料 = 3000 魔力** |
| 消耗速度 | 0.01 单位/秒 → 1 单位烧 100 秒 |
| 折算功率 | **约 30 魔力/秒** |
| 寻找池子 | 半径 6 |
| 空转保护 | 附近没有能接收魔力的池子时**不烧燃料** |

### 太阳花 / 夜颠茄（被动产魔）

不烧任何燃料，直接按时间往**半径 6 格**内的魔力池注魔。

| | 太阳花 | 夜颠茄 |
|---|---|---|
| 造价 | 4 黄花瓣 + 2 魔力尘 | 4 黑花瓣 + 2 魔力尘 |
| 产魔 | **8 魔力/秒** | **4 魔力/秒** |
| 时段 | 只在**白天**（天空光强 > 0.5） | 只在**夜晚** |
| 寿命 | **15 天**后自行枯萎 | **15 天**后自行枯萎 |
| 半径 | 6 | 6 |

- 昼夜判定读的是**实时天空光强**，所以日食、火山灰遮天时太阳花会跟着停；
- 两种花都不需要小人、不需要电，纯粹「种下去就产」；
- 选中时会显示当前状态：正在产魔 / 等白天 / 等夜晚 / 附近没有魔力池 / 还剩几天枯萎；
- **造价极低但会枯萎**，适合当过渡电力，长期供电仍要靠火红莲。

### 魔力通量场（耗魔发电）

- 输出 **1000 W**，同时消耗 **1.5 魔力/秒**；
- 从半径 6 内的魔力池或中继塔取魔，取不到就停转（可以手动断电）；
- 一个满池（100 000）约可供 **18.5 小时** 的 1000 W 输出。

### 魔力中继塔（搬运）

| 项 | 值 |
|---|---|
| 自身缓冲 | 6000 |
| 工作半径 | **8**（向上游池子/塔取，向下游设备供） |
| 搬运速度 | **40 魔力/秒** |
| **损耗** | 每经过一跳 **10%** |

三跳之后只剩 `0.9³ ≈ 73%`，所以长距离供电要算账：能就近建池就别拉长链。

### 荆棘花（防御）

魔力驱动的范围防御花。只要池子里有魔力，任何闯进 10 格的敌对目标都会挨扎。

| 项 | 值 |
|---|---|
| 作用半径 | **10 格** |
| 结算间隔 | **60 tick（1 秒）** |
| 单次伤害 | **3 点切割**（**3 DPS / 目标**） |
| 单次耗魔 | **2 点 / 目标**（**2 魔力/秒 / 目标**） |
| 最大目标 | 12 |
| **自身储能** | **150**，战斗时**先用它**，不够才向网络要 |
| 回充 | **25 魔力/秒**，只在没有敌人时进行（6 秒充满） |
| 减速 | 移动速度 **×0.7**，**不消耗魔力** |

**三个层次的钱包**：先花自己的 150，花完再从网络抽，网络也空了就彻底停手。

**魔力不够时怎么办**：按「能打几个打几个」算。来 10 个敌人、能凑出 8 份就扎最近的 8 个；
下一轮只够 1 份，就只扎 1 个。**不会预支、不会白扣。**

**战斗中不回充**：只有范围内没有敌人时才会把缓冲补满，所以一旦开打，它就是「150 存量 + 实时网络」，
池子断供的那一刻起，150 撑完（75 次命中）就只剩免费减速了。

**只打敌人**：不打自己的小人、盟友和中立商队。倒地的目标也会被放过。

**减速是免费的**：即使池子干了，站在范围内的敌人照样被拖住——它退化成一个路障，但不再掉血。

**耗魔随人数线性增长**：

| 敌人数 | 耗魔 | 相当于 |
|---|---|---|
| 3 | 6 / 秒 | 0.2 朵火红莲 |
| 10 | **20 / 秒** | 0.7 朵火红莲 |
| 20 | 40 / 秒 | 1.3 朵火红莲 |

所以它真正吃的是**持续产能**：袭击规模一大，池子掉得肉眼可见。

> 选中荆棘花会显示「范围内 N 个敌人，魔力够打 M 个」，一眼能看出是不是产能跟不上了。

|---|---|

## 三·二、精灵之门（Alfheim Gate）

| 项 | 值 |
|---|---|

## 三·五、建筑恢复器与装备修复器（耐久维护）

两座建筑共用一套逻辑：**按周期挑最破的目标，用魔力把耐久补回去**。

| | 建筑恢复器 | 装备修复器 |
|---|---|---|
| 修什么 | 自己阵营的**建筑**（墙、门、家具、设备） | 地上 / 仓库里的**物品**（武器、工具、服装） |
| 工作半径 | **8 格** | **6 格** |
| 每周期（1 秒） | 默认最多 **5** 个目标，每个最多 **+5 耐久** | 默认最多 **5** 个目标，每个最多 **+6 耐久** |
| 魔力价 | **5 魔力 / 点耐久** | **5 魔力 / 点耐久** |
| 满负荷耗魔 | 125 魔力/秒（5 目标） | 150 魔力/秒（5 目标） |
| 取魔半径 | 6 格（池 / 中继塔） | 6 格（池 / 中继塔） |

耗魔直接可算：**魔力 = 魔力价 × 每点耐久 × 目标数**。
例如 10 面墙各修 5 点耐久 = 5 × 5 × 10 = **250 魔力**。

共同规则：

- **越破的优先**，所以火力不会全堆在一面满血的墙上；
- **按实际抽到的魔力打折**：魔力只够修 3 点就只修 3 点，不会扣了魔力不干活；
- **抽不到魔力就完全停手**，不空转、不扣费；
- **只管修，不管盖**：蓝图、框架、正在施工的东西一律跳过（那是建造工作的活）；
- **不碰别人的东西**：其他阵营的建筑不修；人、尸体、植物也不修；
- 选中后有「**修复开关**」（扳手图标）可以随时暂停，检视里会显示工作半径和上周期实际修了多少耐久；
- 选中或**放蓝图**时都会显示作用范围。

### 目标上限（模组设置）

选项 → 模组设置 → 植物魔法 里，**建筑修复与装备修复各自独立**：

| 项 | 默认 |
|---|---|
| 限制每次修复的建筑数量 | **开**，每次 **5** 个（1–50 可调） |
| 限制每次修复的装备数量 | **开**，每次 **5** 个（1–50 可调） |

关掉某一项即「范围内所有破损的东西一起修」，耗魔按数量成比例增加。

> 配合活石墙（耐久 600）或魔力钢墙（耐久 1000）使用效果最好——
> 把建筑恢复器放在基地中心，半径 8 格内的破墙会自己慢慢长回来。

## 四、森林法杖（远程武器 + 法术）

### 武器形态

| 项 | 值 |
|---|---|
| 类型 | 主武器（`Primary`），研究「花圃工艺」解锁 |
| 造价 | **12 活木 + 12 活石**，锻造 4 级，手工点 / 燃料锻造台 / 电动锻造台 |
| 耐久 / 质量 / 市价 | 120 / 2.5 kg / 400 |
| 弹丸 | **魔力弹：25 点枪弹伤害、穿透 1.5**（与原版狙击枪子弹完全一致） |
| 射速 | 预热 0.6 秒 + 冷却 1.0 秒 → **约 1 秒一发** |
| 射程 / 精度 | 26 格；**命中率四档统一 80** |
| 近战 | 杖身 7 点钝击 |
| **杖内储能** | **500**，每发消耗 **100** → **满杖 5 发**

与狙击枪对比：

| | 狙击枪 | 森林法杖 |
|---|---|---|
| 单发伤害 | 25 | 25 |
| 预热 + 冷却 | 3.5 + 1.5 秒 | 0.6 + 1.0 秒 |
| 持续输出 | ≈5 DPS | ≈**15.6 DPS**（约 3 倍） |
| 射程 | 44.9 | 26 |
| 总量限制 | 无 | 满杖 **125** 点伤害（5 发），之后必须回充 |

**魔力怎么来**：杖内不够时，开火那一刻就近向 **6 格内**的魔力池/中继塔借；
借不到就**不开火**并提示「魔力不足，打不出这一发」，不会白扣魔力。
所以基地附近几乎不受限，**离开魔力网就只有 5 发**。

**补充魔力有三种方式**：

1. **拿在手里充能**：持杖小人被选中（或征召）后，按钮那一排有「从魔力池充能」，
   站在魔力池 / 中继塔 **6 格**内点一下就把杖补满；
2. **放着自充**：法杖躺在地上（比如池子旁的仓库）时以 **25/秒** 缓慢吸纳；
3. **打空了直接借**：开火那一刻杖内不够，会现场向 6 格内的池子借，借不到才打不出。

### 法杖改型（狙击型 / 爆破型）

研**法杖改型**（2000 点，前置「魔力网络」）后，工作台上多出两个改造配方。
**改造会消耗那根基础法杖**，不可逆，二选一——想要另一种就得再造一根杖重改。

| | 狙击型 | 爆破型 |
|---|---|---|
| 造价 | 法杖 ×1 + 25 活木 + 15 活石 + 20 魔力钢 + 2 零部件 | 法杖 ×1 + 15 活木 + 25 活石 + 20 魔力钢 + 4 零部件 |
| 耐久 / 重量 / 市价 | 140 / 3.0 kg / 900 | 140 / 3.5 kg / 850 |
| 子弹 | 魔力长枪：**50 伤害、穿透 2.4** | 魔力爆弹：**40 伤害**，落点再炸 **10 / 格** |
| 预冷 / 射程 | 1.0 + 1.5 秒 / **40 格** | 1.2 + 3.0 秒 / **16 格** |
| 命中率（近/短/中/远） | **85 / 85 / 85 / 85** | 75 / 70 / 65 / 60 |
| 杖内储能 | **800**，每发 **60** → 满杖 **13 发** | **700**，每发 **60** → 满杖 **11 发** |
| 法术 | **无** | **无** |

**爆破型的十字**：子弹命中一个小人，就**在它脚下**炸一个十字——中心格 + 上下左右，共 **5 格**，不含斜角。
被直接命中的那个小人吃 **40（子弹）+ 10（爆炸中心）= 50**，周围四格各吃 10。
**打空时落点同样会炸**，所以拿来犁阵地、压门口都行。

> **爆炸伤害由模组自己逐格结算**，不交给引擎的爆炸管线。
> 原因：引擎按半径取格时会做视线过滤、并给每个空地补一圈相邻墙体
> （`openCells.Concat(adjWallCells)`），命中格数随地形浮动；实测下来墙体还会
> 稳定吃到面板值的两倍。为了数字可预期，十字的 5 格是算好后直接指定的，
> 每格每物只结算一次。`GenExplosion` 仍然调用，但伤害传 0，只借它的
> 屏幕震动、闪光与爆炸音。

> **面板数字会吃品质加成**：`RangedWeapon_DamageMultiplier` 带品质部件，
> 大师 ×1.25、传奇 ×1.5。所以传奇品质的爆破型子弹是 **60** 而不是 40，
> 狙击型是 **75** 而不是 50。这是原版武器规则。

> 爆炸走的是原版爆炸的表现管线，所以**不分敌我**：自己人、动物、建筑、你自己的墙，一样照炸。
> 射程只有 16 格，站在 16 格内开火的射手自己不会受伤（爆炸点不在脚下），但别让前排挤在落点上。

**两个变体都没有法术**：绽花和就地转化只挂在基础森林法杖上。
改造之后那根杖就只剩开火——想要法术，就得另带一根基础杖（或换回去重造）。

**改造后是满蓄的**：不继承原杖剩下的魔力，改成什么就有一整条。

### 两个法术

**选中持杖小人 → 征召 → 点按钮 → 指定 6 格内的目标格**。

| 法术 | 效果 | 范围 | 消耗 |
|---|---|---|---|
| **绽花** | 让植物立刻长高一截（+25% 成长度，已成熟的不受影响） | 目标格周围 **4** 格 | **20 / 株** |
| **就地转化** | 原木 → 活木、石砖 → 活石，**每堆一次转 10 个** | 目标格周围 **1.5** 格 | **20 / 个**（10 个 = 200），一次最多 9 堆 |

- 技能是**原版灵能技能那套**（`AbilityDef`）：征召后出现在技能栏，外观与用法和灵能技能一致；
- **鼠标悬停在按钮上**才画范围环：**青色 = 施法距离 6 格**，**绿色 = 绽花影响半径 4 格**；
- 点技能按钮后，**影响范围跟着鼠标走**（画在鼠标所在格上）；
- 左键选格 → 范围消失、法术在那一格结算；目标超过 6 格点不下去，会提示超出施法范围；
- 小人身上平时**不会有任何圈**；
- 魔力条（样式参照原版精神力条）就在**征召按钮旁边**，悬停显示每发消耗与剩余发数；
  数值直接读手里那根法杖，所以不同的魔杖有不同的总量与消耗。

> 魔力条走的是引擎给**已装备物品**的 Gizmo 出口
> （`CompEquippable.CompGetEquippedGizmosExtra()`），不依赖任何其它模组，
> 所以装不装 CE 都一样显示。

## 五、研究

独立研究页「植物魔法」，共 17 个项目：

```
神秘花卉 300 ── 魔力 900
                  ├─ 产能花 600 ── 被动产能花 400 ── 进阶产能花 1500
                  ├─ 花圃工艺 900 ── 功能花 1200
                  └─ 魔力钢 1500
                       ├─ 魔力存储 1500
                       │    ├─ 魔力灌注 2400 ── 精灵之门 3500
                       │    │                     ├─ 元素装备 3000
                       │    │                     └─ 泰拉钢 4000 ── 盖亚 5000
                       │    └─ 魔力网络 1800 ── 法杖改型 2000
                       └─ 魔力修补 1200
```

> 「魔力修补」挂在**魔力钢正下方、魔力网络下面**，不挡主路径。

**每个项目解锁什么**：

| 研究 | 花费 | 解锁 |
|---|---|---|
| **神秘花卉** | 300 | 8 种神秘花的**播种** |
| **魔力** | 900 | 魔力尘配方、白雏菊、**简易魔力池（2000）** |
| **产能花** | 600 | 火红莲 |

## 六、玩法流程

1. **开局**：地图上找野生神秘花，采集攒花瓣（顺手采集会刷新）。先研「神秘花卉」把播种开出来。
2. **起手**：3 花瓣 → 魔力尘；再攒 4 白花瓣 + 4 原木造第一座**白雏菊**。
   初期没有魔力池，它会以 **1/5 速度**免费把原木变活木——慢，但足够起步。
3. **发电**：研「魔力」后建**简易魔力池**（15 活石 + 15 活木）+ **火红莲**，塞木头进去。
   白雏菊一旦接上池子就恢复全速，但每次转化要扣 20 魔力。
   早期花瓣有多的话，先摆两朵**太阳花/夜颠茄**顶着，它们不烧燃料但 15 天会枯。
4. **扩产**：白雏菊把石砖变活石 → 用活石砌墙、攒活木活石。
5. **出门装备**：研**花圃工艺**，用 **12 活木 + 12 活石**造**森林法杖**——
   不用魔力钢，2100 点就能拿到。基地里随便打，远征时记住只有 5 发。
6. **储能升级**：研**魔力钢**再研**魔力存储**，用 25 魔力钢 + 20 活木建大**魔力池**，
   把散落在十几个小碗里的储备收进一处。
7. **送电**：研**魔力灌注**后建**魔力通量场**，1000 W 直接进电网；
   离得远就研**魔力网络**建**中继塔**接力（记得算 10%/跳）。
8. **防御**：研**功能花**造**荆棘花**，摆在阵地前沿。它不吃电、不吃人，但一群敌人能让你的池子肉眼可见地掉——记得先补产能。
9. **维护**：研**魔力修补**，基地中心放一座**建筑恢复器**、装备架旁放一台**装备修复器**。
10. **改型**：研**法杖改型**（合计 4100 点）后把法杖改造成**狙击型**（高穿远射）或**爆破型**（落点十字）。
    改造消耗原杖、不可逆，而且**两个变体都没有法术**——法术只属于基础杖。

## 八、安装

1. 到 [Releases](https://github.com/moxuanag/Rimworld-Botania/releases) 下载最新 zip；
2. 解压出 `Botania` 文件夹，放进 `RimWorld/Mods/`；
3. 在模组列表启用「植物魔法 Botania」，排序放在 Core 之后、**Harmony（brrainz.harmony）之后**。

> **0.6.0 起 Harmony 是硬依赖。**
>
> 电暴花需要在原版的电网短路发生时拿到那一刻的储能，而引擎没有开放事件回调，
> 所以只能挂一个 Harmony 补丁，同时挂在两个地方：
>
> - `RimWorld.ShortCircuitUtility.DrainBatteriesAndCauseExplosion(PowerNet, Building, ref float, ref float)`
>   —— 真正把电池抽干的地方，`__args[0]` 就是电网，前缀取储能、后缀按比例分发；
> - `RimWorld.ShortCircuitUtility.DoShortCircuit(Building)` —— 事件入口，作为兜底；
>
> 两处会命中同一次事件，所以 `ShortCircuitAbsorb` 用「同一个 culprit + 同一 tick」去重，
> 不会重复吸取。补丁全程 try/catch，出错只记警告，不影响原版短路本身。
>
> 缺 Harmony 的后果：`BotaniaHarmony` 的静态构造会抛异常并记一条错误，
> 电暴花永远收不到能量（其余 69 个 Def、其余机制照常工作）。
> `About.xml` 已用 `modDependencies` 声明，模组列表会直接标出缺依赖。
>
> 两个补丁类 `Patch_DoShortCircuit` / `Patch_DrainBatteriesAndCauseExplosion`
> **在代码里没有任何引用**——它们由 `Harmony.PatchAll()` 反射扫出来。
> 改名字或删掉会让补丁静默失效，别当成死代码清理。

手动安装（开发用）：

```powershell
git clone https://github.com/moxuanag/Rimworld-Botania.git "RimWorld/Mods/[GZ]Botania"
cd "RimWorld/Mods/[GZ]Botania/Source"
dotnet build -c Release      # 产物：../Assemblies/Botania.dll
```

`Source/Botania.csproj` 用相对路径引用 `..\..\Assembly-CSharp.dll`，
所以仓库必须放在 `Mods\<任意名>\` 下才能编译。

## 九、目录与版本

```
About/           模组元数据（name / packageId / modVersion）
Assemblies/      编译好的 Botania.dll
Defs/            ThingDef / RecipeDef / ResearchProjectDef / ResearchTabDef
Languages/       中文（ChineseSimplified (简体中文)）与英文

Textures/        全部程序化生成的 PNG
scripts/         CI 用的校验脚本
CHANGELOG.md     版本历史
VERSIONING.md    版本号规则（协作硬约定）
```

- 版本号规则见 **[VERSIONING.md](VERSIONING.md)**（这也是给协作者的硬约定）；
- 摘要：**默认走 PATCH（`0.0.X`）**，只有新增物品/机制或破坏存档兼容才走 MINOR（`0.X.0`），`1.0.0` 留给核心闭环定稿；
- 判据只有一条：**旧存档能不能直接读**——能读就是 PATCH，读不了才是 MINOR；
- `About/About.xml` 的 `<modVersion>` 是唯一版本来源，**必须与 git tag 一致**（CI 会校验，不一致直接失败）；
- 未发布过的号不补发、不留空号；tag 形如 `v0.4.1`，推 tag 即触发自动打包并发布 Release。

> ⚠️ 语言目录名必须是 `ChineseSimplified (简体中文)`（与引擎语言身份一致）。
> 写成裸 `ChineseSimplified` 会导致**整包翻译不加载**，游戏里全是英文。

## 十、已知限制与后续

- **花药台（Petal Apothecary）不做**：MC 里它存在的理由是「花不能像作物一样种」，
  而这里的神秘花本来就是可播种作物、功能花也能直接建造，再加一道仪式只会是多余手续。
- **活石本身不会自愈**：耐久维护交给**建筑恢复器**（范围修复），材料自己不会长回来。
- **法杖命中处的 3×3 爆炸**：已记录，暂缓实现。
- **修复器只修耐久**：不修「已损毁」的东西（彻底毁掉的救不回来），也不参与建造。
- **全图抽取**：计划作为后期科技解锁，接口已收敛在 `Source/IManaSource.cs` 的 `ManaSourceUtil.FindNearest`。
- 8 色花目前只有颜色差异，未来考虑给主色加差异化功能。
- 3 个研究项目（元素装备、泰拉钢、盖亚）目前是占位，解锁内容尚未实装。
- 火红莲单产偏高，等出现更多耗魔设备后再按总账调。
- 「魔力通量场」是否改名「魔力发电机」仍在讨论。
