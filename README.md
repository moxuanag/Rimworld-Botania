# 植物魔法 Botania（RimWorld 1.7）

> 把 Minecraft 的 **Botania（植物魔法）** 搬进环世界：种花产魔、魔力网络、精灵之门、泰拉钢装备，
> 以及一场打穿世界之魂的终局 Boss 战。

## 这是什么

一个**围绕「魔力」运转**的完整科技模组：不再靠发电站，而是**种花**把阳光、燃料、生物质变成魔力，
再把魔力变成材料、装备、建筑与传送门。整条科技线有 **33 项研究**，分成产能花 / 功能花 / 防御花三条支线（每朵花一个研究），从第一朵白雏菊一路走到泰拉钢与盖亚。

## 核心内容

| 模块 | 一句话 |
|---|---|
| **神秘花（8 色）** | 播种、采集花瓣，不同花色合成不同材料 |
| **产魔花 & 功能花** | 太阳花、火红莲、白雏菊、荆棘花、启命英等，各有独立机制 |
| **魔力网络** | 魔力池、中继塔、通量场：储存、搬运、发电 |
| **精灵之门** | 投料自动转化：活木→梦木、活石→精灵石英、花瓣→精灵之尘 |
| **装备线** | 元素 → 泰拉 → **盖亚**三档，含剑、弓、甲、盔、镐，以及可改型的森林法杖 |
| **盖亚 Boss** | 研究泰拉钢后的终局事件：碎块 → 传送门 → 三波防守 → **盖亚·世界之魂** |
| **世界之种苗圃** | 把泰拉钢装备培育成盖亚装备；盖亚套装提供强力加成 |

## 安装

| 方式 | 步骤 |
|---|---|
| **Steam 创意工坊** | 订阅即可，无需其他前置模组 |
| **手动安装** | 把 `Botania` 文件夹放进 `RimWorld/Mods/`，启动器里勾选 |

- **不需要** Harmony、不需要任何 DLC（部分内容会随 DLC 增加，例如异象的肉床）
- 支持中途加入存档；移除前请先卸下模组装备与建筑
