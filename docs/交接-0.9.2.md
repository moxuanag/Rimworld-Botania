## 五、容易踩的坑（本轮已踩过）

1. **控制台编码**：PowerShell 默认 GBK，跑 python 打印中文会 `UnicodeEncodeError` → 先 `$env:PYTHONIOENCODING='utf-8'`。
2. **`ParentName` 只能指向 `Name=` 属性**，不是 defName（`BombSuper` 事件）。
3. **炮塔顶贴图必须朝东**（`ArtworkRotation=-90` 推导），且轴心严格在图中心。
4. **贴图尺寸**：1×1→128、2×2→256、5×5→512；整数倍像素放大用 NEAREST，别用 LANCZOS。
5. **`<building>` / `<mote>` 字段**与本引擎不一致，改前先 `check_xml_fields.py`。
6. **不要首次匹配式替换 XML**，必须整块匹配 + 回读校验。
7. **删除物品**：先扫 `Defs/**`、`Source/**`、`Languages/**`、`Patches/**`、`docs/**` 的引用；注意可能连带孤儿 Hediff / 补丁 / C# 自检。
