## 10. 引擎怪癖 / 踩过的坑（**全部真实踩过**）

1. **`ParentName` 只能指向 `Name=` 属性，不是 defName**。`<DamageDef ParentName="BombSuper">` 会报
   `Could not find parent node named "BombSuper"` → 整个 def 消失。要么引用真父节点，要么写自包含 def。
2. **`MoteProperties` 只有 `growthRate`**，没有 `growRate` / `rotationRate`。
3. **`BuildingProperties.turretTopOffset` 是 Vector2**（不是 Vector3），写三元组会让整个 ThingDef 加载失败，
   连带子 def 与翻译注入报错。
4. **炮塔顶贴图必须朝东（右）**：`DrawTurret` 总旋转 = `ArtworkRotation(-90) + CurRotation`（CurRotation 北=0 东=90），
   Unity `R(90)·forward = right` ⇒ 贴图本身要画朝东。**轴心必须严格在图中心**，否则旋转会漂。
5. **`GenDraw.DrawRadiusRing` 有半径上限** `GenRadial.MaxRadialPatternRadius ≈ 79.8`，超了每帧报错且不画 →
   用 `BotaniaOverlays.DrawRadiusRingSafe`。
6. **自己画 overlay 必须抬到 `AltitudeLayer.MetaOverlays`**，否则被地形盖住（`DrawLineBetween` 要传 layer）。
7. **炮塔靠 `CurrentTarget` 驱动转向**：不要在 `TryFindNewTarget` 里因缺魔返回 Invalid（会完全不转向）；
   缺魔应在**预热阶段**取消（`Building_ManaTurretGun.Tick` 覆写 `burstWarmupTicksLeft = 0`）。
8. **爆炸视觉 ≠ 伤害范围**：`explosionEffect`（如 GiantExplosion）是纯特效，实际范围由 `explosionRadius` 决定；
   逐格火苗靠 `DamageDef.explosionCellFleck` + 颜色。要「看到多大就打多大」须二者匹配。
9. **`statOffsets` 是「加多少」不是「变成多少」**：要 5 倍工作速度写 `4`（基准 1.0）。
10. **限时 Hediff 必须挂 `HediffCompProperties_Disappears`**，否则永久。
11. **自定义 `DamageDef` 必须自带 `hediff`**（或继承有 hediff 的父类），否则受伤逻辑会炸。
12. **`CompFlickable` 有两套状态**（`switchOnInt` 实际 / `wantSwitchOn` 意图）：不要直接写，灯光用 `IThingGlower`。
13. **节流只放一处**：自建 tick 计数与 `IsHashIntervalTick` 不能叠加（相位不同会永不触发）。
14. **存档字段平铺**在 Thing 节点下，**Scribe 键必须带前缀**，否则同物件多组件互相覆盖。
15. **删除物品要先扫引用**：`Defs/**`、`Source/**`、`Languages/**`、`Patches/**`、`docs/**`；
    注意连带孤儿 Hediff / 补丁 / C# 自检（如 `BotaniaMod.cs` 启动自检「补丁没生效」警告）。
16. **XML 改动禁止首次匹配替换**：同名字段在多个组件重复出现，必须整块匹配 + 回读校验。
17. **建筑师菜单排序**：`Designator_Build.Order = ThingDef.uiOrder`，分类内**按 order 升序稳定排序**；
    下拉分组按钮的 Order 取组内第一个 def 的 uiOrder ⇒ **平铺条目的 uiOrder 必须小于折叠组首成员**。
18. **控制台编码**：PowerShell 默认 GBK，跑 python 打印中文会 `UnicodeEncodeError` → 先设 `PYTHONIOENCODING=utf-8`。
19. **贴图尺寸**：1×1→128、2×2→256、5×5→512；整数倍放大用 NEAREST（LANCZOS 会糊掉像素描边）。
    四边留 ≥3px 透明，否则 `validate_mod` 报「贴图外溢」。
20. **DLL 必须比源码新**：`validate_mod.py` 会查 `Assemblies/Botania.dll` 与源码 mtime，改了 C# 记得 build。

## 14. 协作方式（省 token 的工作模式）

用户要求：**主代理只做设计 + 验收，实现交子代理**。

| 角色 | 职责 |
|---|---|
| 主代理（lead） | 出方案、拆任务、定写域、验收（build + check_all + 看代码）、写文档/CHANGELOG、commit |
| 子代理 | 只做具体实现；**不要 commit / push / 部署** |

**派单纪律**：
1. 每个子代理的**写域必须不重叠**（不同文件/目录），否则会互相覆盖。
2. 任务书要自包含：仓库路径、允许改的文件、验收命令、报告格式。
3. 同文件多人改 → 改为「各写各的新文件，主代理合并」。
4. 子代理跑 `check_all` 前要提醒设置 `PYTHONIOENCODING=utf-8`（否则误报编码错误）。
5. 完成后主代理**必须自己再跑一次** `check_all`（子代理的结论只作参考）。
