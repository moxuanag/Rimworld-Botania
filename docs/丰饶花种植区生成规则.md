# 丰饶花 · 生成种植区规则（权威规格）

> 版本：2026-11-27 定稿（v1）
> 适用：`Botania_FertilityFlower` 的「生成种植区」按钮
> **本文件地位**：与代码、任务书、历史讨论冲突时，一律以本文件为准。

---

## G1 入口

- **G1.1** 在 Gizmo 栏新增按钮「**生成种植区**」，图标用原版 `UI/Designators/ZoneCreate_Growing`。
- **G1.2** 按钮始终可见（不受档位/魔力限制）。
- **G1.3** 文案走 Keyed（中英各一套），不得直接写死字符串。

## G2 格集合判定（短路与）

点击时，取**当前有效半径**（含研究升级：5 / 6 / 7）内的每一格，按顺序判断；全部满足才纳入：

| 序 | 条件 |
|---|---|
| G2.1 | **地形可种植**（该格地形支持种作物） |
| G2.2 | 格上**没有任何 `CanOverlapZones == false` 的东西**（墙、建筑等） |
| G2.3 | 该格**不属于任何已有区域**（`map.zoneManager.ZoneAt(cell) == null`） |

- **G2.4** 已被别的区域占用的格：跳过，并累计「跳过数」用于提示；**绝不夺格**。
- **G2.5** 格子上的草 / 树 / 野生作物**不影响**纳入（区域本来就可以包含它们）。

## G3 创建与幂等

- **G3.1** 首次点击：新建 `Zone_Growing`，加入 G2 筛选后的所有格，`SetPlantDefToGrow(当前作物)`，
  然后 `zoneManager.RegisterZone`。
- **G3.2** 再次点击（本花已创建过且区域仍有效）：**只补齐**范围内尚未属于该区域的格，并同步作物；
  不删除区域已有的任何格（玩家手工加的格保留）。
- **G3.3** 若筛选后**一格都没有** → 不创建区域，提示「范围内没有可生成种植区的格子」。
- **G3.4** 区域一创建就要设好作物，不允许出现「区域存在但作物为空」。

## G4 自动扩展（研究升级）

- **G4.1** 当档位变化导致半径变大时（与编号重建同一时机），**自动**把「新增一圈中符合 G2 的格」补进本花区域。
- **G4.2** 若本花尚无区域 → 不自动创建（只在玩家点按钮时创建）。
- **G4.3** 自动扩展不弹提示（避免打扰）；失败静默（例如新增格全被占）。

## G5 作物自动同步

- **G5.1** 玩家更换本花的作物后，**自动**把本花创建的区域的 `PlantDefToGrow` 改为新作物。
- **G5.2** 只同步「本花自己创建的」区域；**绝不改**玩家其它区域的作物。
- **G5.3** 同步不改变区域的格集合。

## G6 有效性判定与重建

区域引用视为**有效**需同时满足：
1. 非 null、未被删除、仍在本图 `zoneManager.AllZones` 中；
2. 是 `Zone_Growing`；
3. **覆盖本花当前位置**（`zone.Contains(parent.Position)`）。

- **G6.1** 任一不满足 → 视为失效（例如玩家删了区域、花被搬走）。点按钮时**新建**一个区域；
  旧区域**不删除**（属于玩家资产）。
- **G6.2** 花被拆除时不删区域。

## G7 提示文案

| 场景 | 文案（中文） |
|---|---|
| 创建成功 | 已生成种植区（{0} 格） |
| 补齐成功 | 已补齐种植区（新增 {0} 格） |
| 有格被跳过 | 另有 {0} 格已被其它区域占用，未纳入 |
| 无格可放 | 范围内没有可生成种植区的格子 |

- 前两种用 `MessageTypeDefOf.PositiveEvent`，后两种分别用 `NeutralEvent` / `RejectInput`。

## G8 存档

- 区域引用用 `Scribe_References` 保存（键名 `botaniaFertilityGrowZone`）。
- 读档后按 G6 校验；失效则清空引用（不删区域）。

## G9 多花与边界

- **G9.1** 多朵丰饶花各自维护自己的区域；重叠区按「先到先得」，后创建的花跳过已占格（G2.3）。
- **G9.2** 花被重新安装到别处：旧区域仍在原地（不删），新位置点按钮会新建区域。
- **G9.3** 区域格数上限 = 当前半径内符合 G2 的格数，不做额外限制。

## G10 明确禁止

- 禁止把格从**任何**已存在的区域里抢走。
- 禁止删除或清空玩家已有的区域。
- 禁止修改其它区域的作物设置。
- 禁止在没有任何合格格时创建空区域（空区域会被引擎自动注销）。

## G11 验收清单

1. 点按钮 → 生成一个 `Zone_Growing`，格数 = 半径内「地形可种 + 无阻挡建筑 + 未被占用」的格数；
2. 区域的作物 = 花当前选定的作物；
3. 再点一次 → 只补齐、不重复、不报错；
4. 玩家先画了自己的种植区 → 本花跳过那些格，提示跳过数量；
5. 研究升级 → 本花区域**自动**多出新增一圈的合格格；
6. 换作物 → 本花区域作物跟着变，别的区域不变；
7. 手动删除本花区域后点按钮 → 重新创建；
8. 把花搬到别处 → 旧区域不动，点按钮在新位置建新区域；
9. 建在岩石上（半径内无可种格）→ 不创建、红字提示；
10. 存档读档后，区域引用仍有效且不重复创建。
