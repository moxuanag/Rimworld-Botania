## 1. 目标

| 中文名 | defName（暂定） | 性质 |
|---|---|---|
| 荆棘速射花 | `Botania_ThornRapidFlower` | 机枪炮塔：直射连发 |

## 2. 原版参考（实现前必须对齐）

| 用途 | 参考 defName | 要点 |
|---|---|---|
| 自动机枪塔 | `Turret_MiniTurret` + `Gun_MiniTurret` | 无 `CompMannable` 即自动开火；单发 11、冷却 4.8s |
| 自供电自动炮塔 | `Turret_AutoMiniTurret` + `Gun_MiniTurretMech` | 机械族自动炮塔形态 |
| **自动迫击炮** | `Turret_AutoMortar` + `Artillery_AutoMortar` | 无人工、无装填；`forcedMissRadius 10`、`minRange 29.9`、`range 500`、冷却 80s |
| 手动迫击炮 | `Turret_Mortar` + `Artillery_Mortar` | 需要 `CompChangeableProjectile` + 人工 |
| DLC 形态 | Anomaly `Turret_TacticalTurret`、`FleshmassSpitter`（isMortar）、Odyssey `Turret_AncientArmoredTurret` | 美术与字段参考 |

引擎结论（decomp 已确认）：

- `Building_TurretGun.Active`：`powerComp == null` 即视为有电 → 不装电源组件就不会因断电停机
- `Tick()` 开火条件含 `mannableComp == null || MannedNow` → **去掉 `CompMannable` = 全自动**
- `BeginBurst()` / `BurstComplete()` / `BurstCooldownTime()` 为 `protected virtual` → 魔力付费点
- `TryFindNewTarget()` 为 `public virtual` → 无魔力时返回 Invalid 可避免空预热
- `CanSetForcedTarget` 为 `protected virtual` → 可放行玩家强制目标
- `BuildingProperties.IsMortar` 是计算属性：炮械主 verb 的 `defaultProjectile.projectile.flyOverhead == true` 即算迫击炮

## 3. 共享框架

新增 `Source/Framework/CompManaTurret.cs`：

| 类型 | 职责 |
|---|---|
| `CompProperties_ManaTurret : CompProperties_ManaDevice` | 复用 S1 框架配置，新增 `manaPerBurst` |
| `CompManaTurret` | 组合 `ManaDeviceCore`：`TryPayBurst()`、inspect 文案、停火开关 Gizmo |
| `Building_ManaTurretGun : Building_TurretGun` | override `BeginBurst`（先付款）、`TryFindNewTarget`（无魔力不索敌）、`CanSetForcedTarget`（可选放行） |

**继承而不是复制**，让其它炮塔模组的 Harmony 补丁继续生效。

## 5. 兼容性要点

- 自建抽象父模板（不继承 Core 的 `AutocannonTurret` 等易被改的中间层），字段值参考原版但写自己的一份
- 不装 `CompPowerTrader` / `CompMannable` / `CompChangeableProjectile` / `CompRefuelable` → 与"免电炮塔""弹药""炮塔增强"类模组互不干扰
- 索敌走原版 `AttackTargetFinder`，与普通炮塔一致；异象实体能否被锁定需实测
- 组件存档键必须带前缀（见 `AGENTS.md` §6）
