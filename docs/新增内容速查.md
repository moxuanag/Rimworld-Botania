# 新增内容速查（给「不用很懂这个模组」的模型/人）

> 目标：**填名字和数字就能加内容，错了有脚本拦**。不需要读整个代码库。
> 三条命令，按你要加的东西选一条。

---

## 0. 开工前（10 秒）

```powershell
cd D:\SteamLibrary\steamapps\common\RimWorld\_dev\Botania-src
python scripts\check_all.py --fast    # 先确认当前是全绿的
```

## 1. 加「物品」（材料、宝石、道具）

```powershell
python ..\_botania-dev\scaffold_apply.py item Botania_TestGem ^
    --label-zh 测试宝石 --label-en "test gem" ^
    --stack 75 --market 80 --mass 0.2 ^
    --cost Botania_ManasteelIngot:2 --research Botania_Manasteel
```

自动生成并落位：

| 产物 | 路径 |
|---|---|
| ThingDef | `Defs/ThingDefs_Items/Items_Botania_<短名>.xml` |
| 占位贴图 | `Textures/Things/Item/Botania/<短名>.png` |
| 中文 label/描述 | `Languages/ChineseSimplified (简体中文)/DefInjected/ThingDef/Botania_Things.xml` |

然后它会**自动跑 check_all**，全绿才算完成。

- 可用参数：`--desc-zh`、`--desc-en`、`--cost 材料:数量`（可重复）、`--research`
- 想看会写哪些文件不落盘：加 `--dry-run`
- **注意**：物品默认**没有获取方式**（没配方）。要能做出来需要另加 `RecipeDef` —— 这一步暂时没有模板，搜现有 `Defs/Recipes/` 照抄一份。

## 2. 加「建筑」（不耗魔的普通建筑）

```powershell
python ..\_botania-dev\scaffold_apply.py building Botania_TestLamp ^
    --label-zh 测试灯 --label-en "test lamp" ^
    --group Botania_Buildings --hp 120 --work 400 --mass 3 ^
    --cost Botania_ManasteelIngot:4 --research Botania_ManaStorage
```

- `--group` 只能选这五个（决定它出现在建筑师菜单的哪个分组）：
  `Botania_ProduceBuildings` / `Botania_Buildings` / `Botania_ManaFlowers` /
  `Botania_FunctionFlowers` / `Botania_DefenseFlowers`
- 生成的建筑**没有魔力逻辑**。要耗魔/产魔 → 用下面的「3. 加会耗魔的东西」。

## 3. 加「产魔花 / 耗魔设备 / 炮塔花」（要写 C#）

```powershell
python ..\_botania-dev\new_content.py produce-flower Botania_TestBloom --label "test bloom"
python ..\_botania-dev\new_content.py mana-device   Botania_TestDevice
python ..\_botania-dev\new_content.py turret-flower Botania_TestTurret
```

它会把 C# 骨架写进 `Source/`，再在 `_dev/_botania-dev/scaffold_out/` 生成 Def 片段、
中英 Keyed、DefInjected 片段、占位 PNG 和 `*.next-steps.txt`（**下一步清单**）。
按清单把片段贴进对应文件，然后跑 `check_all.py`。

**框架选择（一句话）**：耗魔/产魔一律继承现有基类，不要自己抄「找魔力源 / 定时结算 / 存档 / inspect」：

| 要做的 | 继承/组合 |
|---|---|
| 耗魔设备、功能花 | `CompManaDevice` + `ManaDeviceCore`（`Source/Framework/ManaDeviceCore.cs`） |
| 产魔花 | `CompManaProducer`（`Source/Framework/ManaProducerCore.cs`） |
| 炮塔 | `Building_ManaTurretGun`（`Source/Framework/ManaTurretCore.cs`） |
| 带作用范围 | `CompProperties_RadiusRing` + `PlaceWorker_RadiusFromComp`；画圈用 `BotaniaOverlays.DrawRadiusRingSafe()` |

## 5. 报错怎么看（脚本已经替你查了这些）

| 报错 | 意思 | 改哪里 |
|---|---|---|
| `XML 组件字段与 C# 属性类不匹配` | XML 里写了组件不存在的字段 | 那个 XML 的那一行 |
| `<building> 里没有字段 'xxx'` | `BuildingProperties` 没这个字段（本引擎和原版有差异） | 删掉或换字段；拿不准先查 decomp |
| `ParentName="X" 没有对应的 Name=` | 父节点只能指向 `Name=`，不是 defName | 改成真父节点，或把字段抄全写自包含 def |
| `找不到贴图` | texPath 指向的 png 不存在 | 补图或改 texPath |
| `缺少中文 label` | 没写 DefInjected | 补 `Languages/.../DefInjected/<Def类型>/` |
| `不透明区水平中心偏离` | 炮塔顶贴图左右不对称，旋转会漂 | 把圆心画到 (64,64) |

## 6. 三条最容易犯的错（脚本也拦不住的）

1. **`statOffsets` 是「加多少」不是「变成多少」**：要 5 倍工作速度写 `4`（基准 1.0）。
2. **给玩家的限时效果要挂 `HediffCompProperties_Disappears`**：否则永久生效。
3. **不要因为「没魔力」就不索敌**：炮塔靠 `CurrentTarget` 驱动转向，缺魔要在发射时拒绝，不是索敌时。
