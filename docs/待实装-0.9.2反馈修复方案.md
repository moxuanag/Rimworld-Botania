## 1. 白雏菊的开关没有图标

**定位**：`Source/CompManaTransmuter.cs:283` 的 `Command_Toggle` 只写了 `defaultLabel` / `defaultDesc`，
**没有 `icon`**，而且文案是硬编码中文（英文环境不翻译）。原版 `Command_Toggle` 不给 icon 时显示空图，
所以「白花的开关没图标」。

**修法**
- 补图标：新增 `Textures/UI/Commands/Botania_DaisyToggle.png`（32×32，与现有 `Botania_GateToggle` 同风格），
  写在 `CompProperties_ManaTransmuter` 上做字段 `toggleIcon`（框架化：未来任何"转化开关"都能复用）。
- 文案改 Keyed：`Botania.DaisyToggle.Label` / `.Desc`（中英各一份）。
- 兼容：纯 UI 改动，无存档影响。

## 4. 魔杖：显示「还能打多少发」

**现状**：`CompWand` 已有魔力储备条，但没有"可发射数"。

**修法（框架化）**
- 在 `Framework/ManaItemCore.cs` 增加通用方法：
  `public int ShotsRemaining(float manaPerShot)` → `floor(CurrentMana / manaPerShot)`。
- 法杖/弓/任何魔力武器都复用；inspect 里追加一行：
  `魔力：120/500（可发射 4 发）`。
- `manaPerShot` 取自投射物/verb 的消耗字段（若现在写在代码里，先抽到 Def 字段）。
- 文案 Keyed：`Botania.WandShots`（中英）。

## 7. 神秘花颜色 & 炮塔尺寸／间隔

**7.1 神秘花默认只有白色**
- 现状：`Botania_MysticFlower_White/Orange/Yellow/Cyan/Purple/Green/Red/Black` 8 色都能野生生成。
- 目标：野外只生成白色；其它 7 色改为**只能通过制作/种植获得**。
- **待确认 ⚠️** 获取方式二选一：
  - A：白色花瓣 + 对应染料 → 配方产出该色花瓣（简单，纯物品配方）；
  - B：研究后可在花盆/农田种植对应颜色（需要 PlantDef + 种子物品，工作量大）。

**7.2 爆萼花（迫击炮花）**
- 射击间隔 20s → **40s**（`turretBurstCooldownTime 20 → 40`）
- 尺寸 1×1 → **2×2**（贴图重画 256×256，`turretTopDrawSize 2`，炮口偏移同步）

**7.3 远古陨击花（陨石花）**
- 尺寸 2×2 → **5×5**（贴图 512×512，`turretTopDrawSize 5`，炮口偏移 ~4 格）
- 5×5 需要确认 `PlaceWorker` 不冲突、造价/耐久同步上调。

## 9. 财富值按强度重设

**方法**：以原版同类为锚点 + 强度系数，并加一个脚本 `balance_audit.py` 检查区间。

| 类别 | 定价公式 | 锚点 |
|---|---|---|
| 材料 | 按工艺链深度 | 魔力粉 3 / 秘银 8 / 元素 16 / 泰拉 700（现有） |
| 魔法武器 | 原版同类 × 强度比 | 森林≈突击步枪 460；狙击≈电荷标枪 900；爆破≈手雷 260 |
| 护甲 | 原版同类 × 强度比 | 元素/泰拉 ≈ 圣装 2000 级；盖亚 ≈ 圣装 ×1.2 |
| 建筑（产魔） | 材料成本 + 产能 × 120 | 魔法池/火红莲等 |
| 炮塔 | `combatPower` × 15 + 材料 | 荆棘钟 200 / 爆萼 200 / 陨击 420 |

**待确认 ⚠️**：整体基调要"对齐原版"还是"略高于原版"？这决定系数。

## 10. 科技线重构（分开三条分支 + 单花研究）

**现状问题**：`Botania_Flowers → BasicMana` 之后是 `GeneratingI/II`、`Garden → FunctionalI`、`DefenseI/II/III`，
一棵树上混着"机制研究"和"花"，而且约 20 朵花没有独立研究条目。

**目标结构**（用户描述）

```
花药台（Botania_BasicMana）
├─ 产能花（GeneratingI）
│    ├─ 太阳花 / 夜颠茄（PassiveGenerating）
│    ├─ 火红莲（Endoflame）
│    ├─ 电暴花 / 苦丽花 / 阿卡纳蔷薇 / 生命兰 / 世界种子 …
│    └─ 炉心蕙（GeneratingII）
├─ 功能花（FunctionalI）
│    ├─ 白雏菊 / 明心莲 / 荆棘花 / 修复器 …
└─ 防御花（DefenseI）
     ├─ 荆棘钟花 / 爆萼花 / 远古陨击花
```

**每个研究条目包含**
- `description`：这朵花怎么工作（产魔来源、触发条件、范围）
- 公式写在哪：RimWorld 研究条目只有 `description` 一个文本位 —— 计划在描述里给出**结论性公式**
  （如「产量 = 房间面积^0.5 × 温度系数，上限 60/s」），完整推导放 `docs/玩法指南.md` 并在描述末尾指路。

**规模**：约新增 **18~23 个** 单花 `ResearchProjectDef`，并重排所有坐标（x=分支，y=层级）。
**兼容**：老档已解锁的旧研究保留；新增研究需要补研究点数。
