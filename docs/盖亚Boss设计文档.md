# 盖亚·世界之魂 Boss 设计文档

> 状态：设计定稿，未实现
> 最后更新：2026-11-16
> 参考机制：原版重型机械族 `Mech_Diabolus`（射线/巨体）、`Mech_Warqueen`（召唤）、`Mech_Apocriton`（复活/光环）

---

## 1. 总体流程

```
完成研究 Botania_Terrasteel
   ↓ 3~5 天后（首次剧情触发）
【事件】天降盖亚碎块（落点：15 格内无玩家建筑，否则改地图边缘空地）
   ↓ 玩家摧毁碎块（结构值 800）
【盖亚传送门】生成
   ↓ 开始 3 波防御（6 / 8 / 10 只，间隔 90 秒，波次间传送门熄火）
3 波清空
   ↓ 传送门充能 5 秒
【Boss 登场】盖亚·世界之魂
   ↓ 三阶段战斗
死亡 → 分解为掉落（不留尸体）
```

- 实力门槛：**不需要**。完成泰拉钢研究时已属中后期。
- 碎块事件：**每存档首次必触发**；之后每 30 天最多触发一次。
- 全局同时只能存在 1 只盖亚 boss。

## 2. 传送门

| 项 | 设计 |
|---|---|
| 可攻击性 | **不可被攻击、不可被破坏** |
| 波次管理 | 3 波，间隔 90 秒；波次之间熄火（不刷怪，玩家可修墙布防） |
| 刷怪点 | 传送门周围 8 格 |
| Boss 出场 | 3 波清空 → 充能 5 秒 → boss 从门中走出 |
| 王在场期间 | 传送门无敌、不可交互 |
| **投降按钮** | Gizmo「停止仪式（投降）」：boss 与小怪化为光被吸回门内；**不算击杀、无掉落** |
| 投降后 | 原地留下**熄灭的传送门**（不可攻击、不可破坏），进入 **1 天冷却**；冷却结束恢复可交互，可重新召唤 |

| 攻击性 | 只针对殖民者与阻挡物；不追杀动物 | |

## 4. 护盾 / 瘫痪 / 锁血

### 4.1 护盾

| 项 | 值 |
|---|---|
| 耐久 | 阶段 I **300** / II **400** / III **500** |
| 减伤 | 80%（受到伤害 ×0.2） |
| 每阶段破盾次数 | **2 次** |
| 恢复 | 瘫痪结束**瞬间回满**；阶段锁血时也瞬间回满 |
| UI | 血条下护盾条 + 破盾提示 + 瘫痪倒计时 |

### 4.2 瘫痪

| 项 | 值 |
|---|---|
| 触发 | 护盾耐久归零 |
| 时长 | **20 秒** |
| 期间 | 不能移动、不能攻击、不能施法 |
| 期间受伤 | **×1.5（150%）** |
| 生效部位 | 全身（不走部位判定，直接对本体） |

### 4.3 锁血（阶段过渡）

| 项 | 值 |
|---|---|
| 触发 | 血量落到 66% / 33% |
| 时长 | **5 秒** |
| 期间 | **完全无敌**（伤害归零）、原地咆哮、形态升级特效 |
| 结束时 | 护盾瞬间回满，进入下一阶段 |
| UI | 头顶「无敌」图标 + 5 秒倒计时；受击跳「免疫」飘字；全图信件「盖亚锁住了伤势，正在蜕变」 |

### 4.4 状态机

```
阶段 I（护盾 300）
  破盾#1 → 瘫痪 20s（×1.5）→ 护盾瞬满
  破盾#2 → 瘫痪 20s（×1.5）→ 护盾瞬满
  血量 66% → 锁血 5s → 阶段 II
阶段 II（护盾 400，新增魔力射线 + 召唤）
  两次破盾循环 → 血量 33% → 锁血 5s → 阶段 III
阶段 III（护盾 500，狂暴 + 世界之魂）
  两次破盾循环 → 血量 0 → 死亡
```

## 6. 世界之魂（扩散冲击波）

| 项 | 设计 |
|---|---|
| 蓄力 | 20 秒，boss 原地不动、无敌 |
| 形态 | **红色冲击波从 boss 中心向外扩散**，速度 **2.5 格/秒**，20 秒覆盖 **50 格** |
| 地面标记 | 波前为红色光带，扫过的格子变红（危险区可视） |
| **墙壁阻挡** | 冲击波遇到墙/门停止扩散，**墙后格子为安全区（完全免伤）** |
| 伤害 | 波前扫过时对该格内目标造成 **90 伤害 + 眩晕 2s**；每个目标只吃一次 |
| 安全判定 | 以 boss 为源点做 `GenSight.LineOfSight`，无视线则免伤 |
| 警告 | 全图信件「盖亚的世界之魂失控了——躲到墙后面！」+ 20 / 10 / 3 秒各提示一次 |
| 表现 | 波前红光 + 震屏随半径增强 |
| **性能** | 每 **0.1 秒**推进一次波前；只处理新扫过的一圈格子；LOS 每目标只算一次 |

## 7. 波次小怪（盖亚造物）

| 项 | 值 |
|---|---|
| 参照 | 原版炽蚕 `Mech_WarUrchin`（healthScale 1.3 / bodySize 0.3 / speed 4.2） |
| 我们的数值 | 自爆型 healthScale **0.9** / 远程型 **1.2**；bodySize 0.35；移速 **3.6** |
| 武器 | 近战自爆（30 伤害 / 2 格）/ 远程孢子弹（12 伤害） |
| 数量 | 第 1 波 6 只、第 2 波 8 只、第 3 波 10 只 |
| **AI** | 优先攻击殖民者；**攻击不到就去拆玩家建筑**；距传送门超过 40 格自动回门附近待命 |

## 10. 实现顺序

| 顺序 | 内容 | 交付标准 |
|---|---|---|
| 1 | 事件链：碎块 → 传送门 → 3 波防御 → 投降 Gizmo | 进游戏能走完全流程（boss 用占位贴图） |

| 5 | 美术：boss、小怪、碎块、传送门、特效 | 替换占位图 |
| 6 | 调试工具全程同步 | 每个阶段配套 |

## 11. 已知风险与对策

| 风险 | 对策 |
|---|---|
| 一个瘫痪窗口打穿一个阶段，第二次破盾形同虚设 | 先按当前数值实现，实测后调 `healthScale`（26 → 45~60） |
| Boss 拆墙把基地拆光 | 每 3 秒最多拆 1 面；不拆基岩 |
| 小怪把基地拆成废墟 | 只有打不到殖民者时才拆，且只拆挡路建筑 |
| 扩散波卡帧 | 0.1s tick + 只算新一圈 + LOS 缓存 |
| 玩家用「回」字形围墙废掉世界之魂 | 保持墙后完全免伤（已定），靠其余技能维持压力 |
| 存档兼容 | `MapComponent` 的 `ExposeData` 必须写全；缺失 def 要容错 |
